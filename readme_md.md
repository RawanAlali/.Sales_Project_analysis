# Sales Data Analysis Project | مشروع تحليل بيانات المبيعات

---

## 🌐 English Version

### 📌 Overview
This project focuses on analyzing sales data using SQL to uncover business insights regarding sales performance, customer behavior, and product analytics. The project follows an end-to-end data pipeline from database schema creation to generating finalized business reports.

---

### 📁 Repository Structure

#### 1. Database Setup & Data Ingestion
* **`create_table.sql`**: Contains DDL queries to create relational database tables and schemas.
* **`fact_sales.csv`**: Raw dataset containing transactional sales records.
* **`insert_data.sql`**: SQL scripts to populate the created tables with data.

#### 2. Data Analysis Pipeline
* **`Exploratory Data Analysis.sql`**: Initial exploratory analysis (EDA) to check data distributions, summary statistics, and identify data patterns or anomalies.
* **`Data Analysis.sql`**: Advanced SQL queries executing deep-dive analytical tasks and answering core business metrics.

#### 3. Reports & Insights
* **`Customer Report.sql`**: Generates targeted insights into customer purchasing habits, segmentation, and lifetime value.
* **`Product Report.sql`**: Summarizes product performance, identifying top-performing items and revenue contribution.

---

## 🌐 النسخة العربية

### 📌 نبذة عن المشروع
يركز هذا المشروع على تحليل بيانات المبيعات باستخدام لغة SQL لاستخراج رؤى قيمة حول أداء المبيعات، سلوك العملاء، وأداء المنتجات. يتبع المشروع مسار عمل متكامل بدءاً من بناء هيكلية قاعدة البيانات وصولاً إلى إعداد التقارير النهائية.

---

### 📁 هيكلة المشروع

#### 1. إعداد قاعدة البيانات وتعبئتها
* **`create_table.sql`**: يحتوي على استعلامات DDL لإنشاء الجداول والهيكلية الخاصة بقاعدة البيانات.
* **`fact_sales.csv`**: ملف البيانات الخام الذي يحتوي على سجلات المبيعات والعمليات.
* **`insert_data.sql`**: السكريبتات الخاصة بإدخال وتعبئة البيانات داخل الجداول.

#### 2. مرحلة تحليل البيانات
* **`Exploratory Data Analysis.sql`**: التحليل الاستكشافي الأولي (EDA) للتحقق من توزيع البيانات، الإحصائيات الوصفية، واكتشاف الأنماط.
* **`Data Analysis.sql`**: استعلامات SQL متقدمة لإجراء التحليل العميق والإجابة عن الأسئلة الخاصة بمؤشرات الأداء الرئيسية.

#### 3. التقارير والنتائج
* **`Customer Report.sql`**: استخراج تقارير تفصيلية عن سلوك العملاء الشرائي وتحديد الفئات الأكثر قيمة.
* **`Product Report.sql`**: ملخص لأداء المنتجات لتحديد المنتجات الأكثر مبيعاً والأعلى مساهمة في الإيرادات.
